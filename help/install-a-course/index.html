How to install a course in Yaaddi

Short answerOpen the Course Library from the Learn tab, find a course and tap Install. The course downloads to your phone and appears on the Learn tab, ready to study offline.

Get started · Last updated 2026-11-18 · For the Yaaddi Android app

Steps

  1. Open the Learn tab and tap the Course Library button (the shop icon at the top right). On a fresh install you can also tap Browse course library.

  2. Scroll the list or type in Search courses. Tap a tag, such as python or ai, to filter. Read more shows the full description and what is inside.

  3. Tap Install on the course you want. The app shows Downloading, Reading course and Saving course, then the button changes to Installed.

  4. Go back to the Learn tab. Tap the course card to open its map and start with the first deck.

Good to know

  • The library needs an internet connection. Once a course is installed you can study it without one.
  • Courses come from a public GitHub repository run by Yaaddi. The app does not send an account or any personal identifier when it downloads them.
  • Installing a course does not change courses you already have. Your progress is stored on your phone.
  • You can also browse every course, with its full list of decks, on courses.yaaddi.com before you install.

Common questions

Why is the Course Library empty or not loading?

The library is downloaded when you open it, so it needs a connection. Check your internet, then open it again. The message Could not load the course library means the download failed.

Do courses cost anything?

No. Yaaddi and all the courses in the library are free.
