Question types in Yaaddi

Short answerYaaddi has 20 question types. You answer by choosing, ordering, matching, sorting, typing or filling in a blank, instead of flipping a card and grading yourself.

Study · Last updated 2026-11-18 · For the Yaaddi Android app

The 20 types

  • Multiple choice
  • True or false
  • Put in order
  • Type the answer
  • Type a short answer
  • Type the number
  • Fill in the blank (tap)
  • Select all that apply
  • Match the pairs
  • Pick the icon
  • Fill in the code or command
  • Predict the output
  • Label the diagram
  • Sort into groups
  • Spot the error
  • Listening
  • Reading passage
  • Cloze passage
  • Media card
  • Preview

How answering works

You answer, then tap Check where the card has one. The result appears at once, with an encouraging message and, when the course author wrote one, See explanation. Tap Continue for the next card.

Where practice comes from

Because every question has a right answer, Yaaddi grades it for you. It records only whether you were correct, and the spaced-repetition schedule uses that. A wrong answer is followed by related practice cards. See What practice cards are.

Good to know

  • Preview cards introduce an idea before you are asked about it.
  • Listening cards play audio. If you cannot listen right now, open Course settings in a language course and use Skip listening cards to skip them for 3 hours, today or this session.
  • Cards that need typing are kept to a minimum on purpose, so you can study on a phone without a keyboard getting in the way.

Common questions

What if a question or its answer looks wrong?

Report it from the card. See How to report a mistake in a card.

Can I skip one card?

Yes. In a lesson, open the three-dot menu and choose Skip this card for now.
