How to import a course file into Yaaddi

Short answerOn the Learn tab, tap the three-dot menu, choose Import a course and pick a course file. Yaaddi accepts a course .json file or a course .zip file.

Get started · Last updated 2026-11-18 · For the Yaaddi Android app

Steps

  1. Open the Learn tab and tap the three-dot button at the top right.

  2. Choose Import a course.

  3. Pick the .json or .zip file from your phone. The app shows Validating course, then adds the course to the Learn tab.

Good to know

  • A course that is not valid fails with a message that names the card and the reason, so a mistake in a hand-made file is easy to find.
  • The ZIP form can include pictures and audio. A JSON file can carry the same content as text.
  • To change a course you already imported, use Update from file in the course's menu. See How to update a course.
  • Courses are built from plain CSV files. The public yaaddi-courses organization on GitHub holds the course template and authoring guide.

Common questions

Which file types can I import?

A course .json file or a course .zip file. Both work from the same Import a course option.

Does importing a course upload it anywhere?

No. The file is read on your phone and stored in the app's local database.
